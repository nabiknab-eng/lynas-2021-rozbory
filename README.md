# Lynasova studie 2021 — dva české rozbory

Statický web: https://nabiknab-eng.github.io/lynas-2021-rozbory/

- [Stručný rozbor](https://nabiknab-eng.github.io/lynas-2021-rozbory/strucny-rozbor.html)
- [Podrobný rozbor](https://nabiknab-eng.github.io/lynas-2021-rozbory/podrobny-rozbor.html)

HTML stránky jsou statické, bez externích knihoven, fontů a analytiky. Zdrojové Markdown soubory jsou uloženy vedle HTML.

Rozbory třídí obsah a stanoviska; samostatně nereprodukují klimatické výpočty. Profily pokrývají 19 nejvýše hodnocených souhlasných a 33 unikátních nesouhlasně označených článků. Celkový počet vlastních atribučních prací ve všech 88 125 položkách nebyl určen. Přepočet příloh odhaluje rozdíly oproti popsanému soupisu 31 nesouhlasných položek.
